# Меню Генератор

Локальный Django-проект для создания авторских меню кафе и кофеен Алматы. Встроенный генератор работает без ключей и внешних сервисов. При желании можно задать `GEMINI_API_KEY` в `.env`, чтобы отправлять результаты на редактуру Gemini.

## Запуск в Windows / VS Code

1. Откройте эту папку в VS Code и откройте терминал (`Ctrl+``).
2. Установите зависимости: `python -m pip install -r requirements.txt`.
3. Запустите сервер одной командой: `python manage.py runserver`.
4. Откройте http://127.0.0.1:8000/.

База SQLite и миграции уже подготовлены. При чистом клонировании выполните `python manage.py migrate` перед запуском.

Чтобы включить Gemini, скопируйте `.env.example` в `.env` и добавьте ключ в `GEMINI_API_KEY`.
